# Фінансовий асистент: Telegram-бот з monobank

Telegram-бот, який підключається до monobank, показує виписку, знаходить
«порожні» витрати (азартні ігри, контент для дорослих, лотереї, езотерика)
і виставляє оцінку фінансової дисципліни від 0 до 100.

Усі повідомлення бота українською, зі зверненням на «Ви», без емодзі.

## Можливості

- Підключення monobank через особистий токен (лише читання), кнопка
  підключення одразу після `/start`.
- `/statement` - виписка за останні 30 днів і звіт про порожні витрати.
- `/waste` - перевірка на порожні витрати з поясненням шкоди кожної категорії.
- Оцінка фінансової дисципліни з рівнями: Відмінно, Задовільно, Тривожно, Критично.
- Тестовий режим із демонстраційними транзакціями (`DEMO_MODE=true`).
- Блокування картки через публічний API monobank неможливе, тому реальної
  дії бот не виконує.

## Команди

| Команда | Опис |
|---|---|
| `/start` | Початок роботи, кнопка підключення monobank |
| `/help` | Довідка |
| `/connect` | Підключити monobank |
| `/disconnect` | Відключити monobank і забути токен |
| `/statement` | Виписка та аналіз витрат |
| `/waste` | Перевірка на порожні витрати |
| `/cancel` | Скасувати підключення |

## Технології

- Python 3.11+
- aiogram 3 (Telegram Bot API)
- httpx (запити до monobank API)
- python-dotenv (налаштування з `.env`)
- pytest (тести)

## Структура проєкту

```
finbot/
  bot/        обробники Telegram, тексти, форматування
  banking/    провайдери даних: monobank, демо
  analysis/   пошук порожніх витрат, оцінка
  domain/     моделі даних
  llm/        зарезервовано для інтеграції LLM
  config.py   читання налаштувань
tests/        автотести
```

Бот залежить від абстракції `BankingProvider`, тому демо-режим і реальний
monobank взаємозамінні.

## Запуск

1. Клонуйте репозиторій:

```
git clone https://github.com/kirillkiselov0705-coder/project_hakaton_kizilH.git
cd project_hakaton_kizilH
```

2. Створіть і активуйте віртуальне середовище (Windows):

```
py -m venv .venv
.venv\Scripts\Activate.ps1
```

На Linux і macOS: `python3 -m venv .venv && source .venv/bin/activate`.

3. Встановіть залежності:

```
pip install -r requirements.txt
```

4. Створіть файл `.env` на основі шаблону та впишіть токен бота
   (отримайте його в @BotFather):

```
copy .env.example .env
```

5. Запустіть бота:

```
python -m finbot
```

## Підключення monobank

1. У боті натисніть кнопку «Підключити monobank» або надішліть `/connect`.
2. Відкрийте https://api.monobank.ua/ і підтвердіть вхід QR-кодом у застосунку.
3. Надішліть отриманий токен боту. Повідомлення з токеном видаляється з чату.

## Тестування

```
python -m pytest -v
```

## Безпека

- Токени зберігаються лише в `.env` (він у `.gitignore`) і в пам'яті процесу.
- Токен monobank дає доступ лише до читання виписки.
- Токени, суми й описи транзакцій не потрапляють у логи.
- Після перезапуску бота токени користувачів скидаються, потрібне повторне підключення.

## Обмеження

- monobank дозволяє один запит виписки на 60 секунд, бот кешує відповідь.
- Пошук порожніх витрат працює за ключовими словами в описі транзакції.
- Інтеграція LLM і база відомих мерчантів заплановані як наступні кроки.
